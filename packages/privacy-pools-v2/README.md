# @kohaku-eth/privacy-pools-v2

> [!IMPORTANT]
> THIS PACKAGE IS NOT READY FOR PRODUCTION USE AND CONTAINS UNAUDITED CODE. USE WITH CAUTION AND ENTIRELY AT YOUR OWN RISK. POSSIBILITY OF BREAKING CHANGES IN SUBSEQUENT VERSIONS.

Privacy Pools v2 plugin for Kohaku. It adapts Kohaku's standard plugin and broadcaster interfaces to the Privacy Pools v2 SDK.

This package is a scaffold: the plugin methods are stubs and do not talk to the protocol yet.

## Installation

```sh
pnpm add @kohaku-eth/privacy-pools-v2
```
